# Faz-Tudo

Uma plataforma que conecta clientes a profissionais de serviços residenciais confiáveis, com base em categoria de serviço e localização, permitindo contratação, moderação por administradores e pagamento direto pela plataforma.

## Autores

- Larissa — [larigm](https://github.com/larigm)

## Stack

NestJS,
Prisma,
PostgreSQL,
React
